# Student Life Observation Tracking

## 📌 Project Overview

**Student Life Observation Tracking** is a student-focused application designed to help students observe, track, and improve their daily activities and lifestyles. The system allows students to monitor their daily routines, academic performance, personal development, physical activities, and time management.

The main goal of this project is to encourage students to build positive habits, maintain a balanced lifestyle, and improve their productivity through daily observation and self-reflection.

## 🎯 Objectives

- Track daily activities and routines.
- Monitor class attendance and academic engagement.
- Record daily learning and skill development.
- Observe physical activities, sports, and exercise.
- Track personal habits and daily responsibilities.
- Monitor social media usage and time management.
- Encourage self-reflection and personal improvement.
- Calculate daily performance scores.
- Help students develop a more balanced and productive lifestyle.

## ✨ Key Features

- **User Authentication:** Secure user login and personalized tracking.
- **Daily Activity Tracking:** Record daily tasks and activities.
- **Academic Monitoring:** Track classes and attendance.
- **Habit Tracking:** Observe daily habits and routines.
- **Learning & Skill Development:** Record learning progress and new skills.
- **Physical Activity Tracking:** Monitor sports, gym, and exercise.
- **Daily Life Score:** Evaluate daily progress using a scoring system.
- **Self-Reflection:** Review daily achievements and areas for improvement.
- **30-Day Observation:** Observe lifestyle patterns and progress over 30 days.
- **Progress Monitoring:** Identify habits and activities that need improvement.

## ⚙️ How It Works

1. The student creates an account and logs in.
2. The student records daily activities.
3. The system collects information about academic, personal, and physical activities.
4. The student completes daily self-observation.
5. The system calculates a daily performance score.
6. The student reviews progress over a 30-day period.
7. The student uses the observations to improve daily habits and productivity.
